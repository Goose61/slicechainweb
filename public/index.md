# SlicePay - Crypto payment gateway for SMBs

> Accept USDC and multi-chain crypto via QR checkout, in-person terminals, and a website pay widget for e-commerce.

## Product

SlicePay (Slice Chain) is a crypto payment gateway for small and medium businesses. Merchants receive USDC settlement with transparent platform fees and optional loyalty rewards.

## Website Pay Widget

Developers embed crypto checkout without blockchain code:

- Embed script: `https://pay.slicechain.io/embed.js`
- Mock merchant test page: https://pay.slicechain.io/test-embed.html
- Create invoice: `POST https://api.slicechain.io/api/gateway/create-invoice`

Parameters: `merchantId`, `amountUsd`, `orderId`, `description` (optional), `redirectUrl` (optional).
